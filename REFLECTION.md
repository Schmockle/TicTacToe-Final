# Refleksjon

Jeg valgte React som rammeverk fordi det gjør det enkelt å bygge gjenbrukbare komponenter. Forsiden og øvrige sider benytter en felles **Navbar** og **Footer**, noe som sikrer konsistent navigasjon.

React Router brukes for å demonstrere navigering mellom fire sider: Hjem, Om oss, Tjenester og Kontakt. Designet er bevisst enkelt, men tar utgangspunkt i fargene og strukturen fra Figma‑skissen. Endringer er gjort for å forenkle prototypen og fokusere på funksjonalitet.
